# Employment Equity Data Analysis — 71point4 Assessment

## Project Overview

This project was completed as part of the Junior Data Analyst assessment for 71point4. It explores South African Employment Equity data to investigate workforce composition and gender representation across occupational levels.

The analysis focuses on preparing unfamiliar data, identifying data-quality issues, conducting exploratory analysis, and communicating findings using Python, tables, and visualisations.

## Objectives

* Inspect and clean the supplied Employment Equity datasets.
* Restructure the data into a format suitable for analysis.
* Examine changes in workforce composition between 2013 and 2024.
* Investigate female representation in the overall workforce and top management.
* Communicate key findings through tables, charts, and a written report.

## Tools and Technologies

* Python
* pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## Project Structure

* `Employment_Equity_Analysis.ipynb` — Python notebook containing the data preparation and analysis.
* `report/` — Final analytical report.
* `figures/` — Visualisations generated during the analysis.
* `requirements.txt` — Required Python packages.
* `data/` — Instructions for accessing the input datasets.

## Key Findings

* Female representation in the overall workforce increased from 47.21% in 2013 to 53.79% in 2024.
* Female representation in top management increased from 17.81% to 24.70% over the same period.
* A substantial difference remained between women's representation in the overall workforce and their representation in top management.
* Workforce composition by population group changed over the period examined.

These findings describe the supplied dataset and should not automatically be interpreted as representative of the entire South African labour market.

## How to Run the Analysis

1. Install Python and Jupyter Notebook.
2. Install the packages listed in `requirements.txt`.
3. Place the supplied CSV files in the expected local data directory.
4. Open `Employment_Equity_Analysis.ipynb`.
5. Run the notebook cells in sequence.

## Data Availability

The analysis uses two supplied files: `ee_meta.csv` and `ee_profile_all.csv`.

The original datasets are not included in this repository. Access to the data should follow the applicable assessment instructions and data-provider terms.
